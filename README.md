# CreativeTruth AI MVP (Web HTML/Flask Edition)

An AI-powered advertising intelligence platform built using a Flask backend and a clean HTML/JS/Tailwind frontend.

### Project Setup
1. Extract this repository.
2. Place the dataset folder exactly as named (`PS-02_ad_creative_intelligence`) inside this folder alongside `server.py`.
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

### Execution
Run the Flask server:
```bash
python server.py
```
Then, open your web browser and navigate to:
`http://127.0.0.1:5000`

### Running Tests
```bash
python -m pytest tests.py
```
