Evidence Center & Methodology

How CreativeTruth AI calculates confidence without hallucinating scores.

SUPPORTED

P-value < 0.05 and adequate sample size (N ≥ 3 per group). Evidence reliably supports the stated association under current assumptions.

PRELIMINARY

P-value < 0.15. A directional signal exists, but statistical uncertainty remains. Recommended for A/B testing rather than immediate scaling.

NO CLEAR ASSOCIATION

P-value ≥ 0.15. The available data does not establish a clear difference between the groups. This does not prove no effect exists, only that current data cannot prove it.

INSUFFICIENT DATA

N < 3 per group. Not enough suitable information to assess the claim safely. Requires more accepted creatives.
